Where RHEL comes from

Fedora tries new features, CentOS Stream previews the next release, RHEL is the supported one.

Fedora→CentOS Stream→RHEL→Rocky, AlmaLinux
Debian→UbuntuKali (from Debian)

RHEL packages are .rpm files installed with dnf. Debian and Ubuntu use .deb files with apt.

Terminal, shell, console

Three words that sound the same.

TerminalThe window where I type and read text.
ShellThe program inside that reads my commands. Bash is the default.
ConsoleThe direct connection to the machine. Ctrl+Alt+F3 opens a text one.
TTY and PTS/dev/tty1 is a text console. /dev/pts/0 is a GUI terminal or SSH session.

[user@host ~]$ regular user   [root@host ~]# root, full power

History and chaining
!!Run the last command
!12Run history number 12
a ; bRun both, always
a && bRun b only if a worked
a || bRun b only if a failed
a | bSend a's output into b
