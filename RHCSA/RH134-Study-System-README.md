## 📌 Pro Tips for Faster Progress

- **Never** skip Guided Exercises
- Type every command yourself (don't copy-paste)
- Use `man`, `tldr`, and `--help` constantly
- After finishing a chapter, teach it to yourself out loud (Feynman technique)
- Keep a separate terminal window open just for practice
- When stuck for >10 minutes → log it in Troubleshooting Log and move on
